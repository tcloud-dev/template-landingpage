# Imagens do Projeto

## Como adicionar o logo

1. Copie o arquivo do logo da TOTVS para esta pasta
2. Renomeie o arquivo para `logo.png` (ou ajuste o nome no código)
3. Para melhor resultado, use um logo com fundo transparente (PNG)

## Recomendações:

- **Formato**: PNG com transparência
- **Dimensões**: Largura recomendada de 150-200px
- **Versões**: 
  - Se possível, tenha duas versões:
    - `logo.png` - Logo branco (para fundo azul)
    - `logo-dark.png` - Logo colorido (para fundo branco)
